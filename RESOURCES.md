# 📚 Resources

Free and low-cost resources I'm using to learn.

## Hands-On Practice Platforms
- **TryHackMe** — "SOC Level 1" and "Pre Security" learning paths
- **LetsDefend** — realistic SOC analyst simulation environment
- **CyberDefenders** — blue team CTF-style challenges using real logs/PCAPs
- **Blue Team Labs Online** — investigation-style challenges

## Study Material
- **Professor Messer** — free Security+ (SY0-701) video course
- **CompTIA official objectives (SY0-701)** — exam blueprint, always check the current version
- **MITRE ATT&CK** — framework for understanding adversary tactics & techniques

## Tools to Get Comfortable With
- **Wireshark** — packet capture and analysis
- **Splunk Free** — SIEM practice (free tier for personal use)
- **Security Onion** — free, open-source SOC platform for a home lab
- **Sysinternals Suite** — Windows troubleshooting/forensics tools

## Communities
- r/AskNetsec, r/cybersecurity (Reddit)
- Local/online SOC analyst & cybersecurity Discord servers
- LinkedIn cybersecurity communities — good for following analysts and job postings
