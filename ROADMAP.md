# 🧭 SOC Analyst Roadmap

My personal, evolving roadmap toward becoming a Tier 1 SOC Analyst. I'll check items off and add notes/links as I complete them.

## Phase 1 — Foundations
- [ ] Networking basics: OSI model, TCP/IP, ports & protocols, DNS, DHCP
- [ ] Operating systems: Windows internals & CLI, Linux CLI basics
- [ ] Core security concepts: CIA triad, authentication vs authorization, common attack types
- [ ] CompTIA Security+ (SY0-701) study and exam

## Phase 2 — Core SOC Skills
- [ ] SIEM fundamentals: what a SIEM does, log sources, correlation rules
- [ ] Hands-on with a SIEM (Splunk Free / Security Onion / ELK stack)
- [ ] Log analysis: Windows Event Logs, Linux syslog, firewall logs
- [ ] Packet analysis with Wireshark: reading captures, spotting anomalies

## Phase 3 — Detection & Response
- [ ] Incident response lifecycle (Prepare → Identify → Contain → Eradicate → Recover → Lessons Learned)
- [ ] Introduction to the MITRE ATT&CK framework
- [ ] Threat intelligence basics: IOCs, OSINT, threat feeds
- [ ] Alert triage: how to prioritize and escalate

## Phase 4 — Hands-On Practice
- [ ] TryHackMe "SOC Level 1" learning path
- [ ] LetsDefend SOC simulation exercises
- [ ] CyberDefenders blue team CTF challenges
- [ ] Build a small home SIEM lab (Security Onion or Splunk + VM logs)

## Phase 5 — Job Ready
- [ ] Polish this portfolio repo with completed labs
- [ ] Update resume with skills and certifications
- [ ] Optimize LinkedIn profile, link this repo
- [ ] Practice SOC analyst interview questions
- [ ] Start applying to Tier 1 SOC / Security Operations roles

- This roadmap is a living document — I'll adjust it as I learn what actually matters on the job.
